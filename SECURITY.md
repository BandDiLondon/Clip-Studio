# Sécurité / Security

**Français** | [English](#english)

## Versions suivies
Seule la **dernière version** publiée dans les [Releases](https://github.com/BandDiLondon/Clip-Studio/releases) reçoit
des correctifs de sécurité.

## Signaler une faille
Merci de **ne pas ouvrir d'issue publique** pour une faille de sécurité. Utilise plutôt le signalement privé de GitHub :
onglet **Security** → **Report a vulnerability**.

Indique si possible :
- la version de Clip Studio et le système (Windows, Linux, macOS) ;
- les étapes pour reproduire le problème ;
- l'impact possible.

Clip Studio est un projet personnel, maintenu sur le temps libre : je réponds dès que possible, en général sous
quelques jours, sans délai garanti. Une faille confirmée est corrigée dans une nouvelle version et mentionnée dans le
[journal des versions](CHANGELOG.md).

## Dépendances
Les dépendances Python sont surveillées par Dependabot et mises à jour quand une faille est signalée.

## English

### Supported versions
Only the **latest version** published in the [Releases](https://github.com/BandDiLondon/Clip-Studio/releases) receives
security fixes.

### Reporting a vulnerability
Please **do not open a public issue** for a security vulnerability. Use GitHub's private reporting instead: **Security**
tab → **Report a vulnerability**.

If possible, include:
- the Clip Studio version and the system (Windows, Linux, macOS);
- the steps to reproduce the problem;
- the possible impact.

Clip Studio is a personal project, maintained in spare time: I answer as soon as possible, usually within a few days,
with no guaranteed delay. A confirmed vulnerability is fixed in a new version and mentioned in the
[changelog](CHANGELOG.en.md).

### Dependencies
The Python dependencies are monitored by Dependabot and updated when a vulnerability is reported.
